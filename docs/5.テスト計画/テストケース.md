# チャットWebアプリ テストケース

## 1. 概要

本資料は、チャットWebアプリMVPの機能別テストケースをまとめたものである。

---

## 2. 認証テスト

| ID | 観点 | 手順 | 期待結果 |
|---|---|---|---|
| AUTH-001 | ログイン画面表示 | `/login` を開く | ログイン画面が表示される |
| AUTH-002 | Googleログイン | Googleログインボタンを押す | Supabase AuthのOAuthログインが開始される |
| AUTH-003 | ログイン成功 | Google認証を完了する | `/chats` へ遷移する |
| AUTH-004 | 初回ユーザー作成 | 初回ログインする | `users` テーブルにレコードが作成される |
| AUTH-005 | 既存ユーザーログイン | 2回目以降ログインする | 既存の `users` レコードが使われる |
| AUTH-006 | ログアウト | ログアウトボタンを押す | セッションが消え、ログイン画面へ遷移する |
| AUTH-007 | 未ログインアクセス | 未ログインで `/chats` を開く | `/login` へ遷移する |
| AUTH-008 | 未ログインアクセス | 未ログインで `/users` を開く | `/login` へ遷移する |
| AUTH-009 | 未ログインアクセス | 未ログインで `/profile` を開く | `/login` へ遷移する |
| AUTH-010 | プロフィール表示 | ログイン後 `/profile` を開く | 自分の表示名、メール、アイコンが表示される |
