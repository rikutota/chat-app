# チャットWebアプリ リリース計画書

## 1. 概要

本資料は、チャットWebアプリMVPをVercelへデプロイし、利用可能な状態にするためのリリース計画をまとめたものである。

本アプリは、以下の外部サービスを利用する。

- Vercel
- Supabase Auth
- Supabase PostgreSQL
- Supabase Realtime
- Supabase Storage
- GitHub

## 2. 分割資料

リリース計画は、後から見やすいように以下の3ファイルに分割する。

| ファイル | 内容 |
|---|---|
| `10_release_plan_overview.md` | リリース方針、対象範囲、環境、リリース方式、完了条件 |
| `10_release_steps.md` | Vercel / Supabase設定、デプロイ手順、環境変数設定 |
| `10_release_checklist.md` | リリース前チェック、リリース後確認、切り戻し手順 |

## 5. リリース方針

MVPでは、Vercelへの通常デプロイを行う。

```text
GitHub main branch
  ↓
Vercel Production Deploy
  ↓
公開URLで動作確認
```

## 6. リリース方式

MVPでは一括リリースとする。

| 項目 | 内容 |
|---|---|
| 方式 | 一括リリース |
| デプロイ先 | Vercel |
| DB | Supabase |
| リアルタイム | Supabase Realtime |
| ファイル保存 | Supabase Storage |
| 切り戻し | Vercelの過去デプロイへ戻す |

## 8. リリース前提条件

リリース前に以下を満たしていること。

```text
・MVP機能がローカルで動作している
・テスト計画の主要ケースが完了している
・Critical / High 不具合が0件
・READMEが更新されている
・.env.exampleが更新されている
・Supabaseのテーブルが作成済み
・Supabase AuthのGoogleログインが設定済み
・Supabase Storageバケットが作成済み
・Supabase Realtimeが有効
・Vercelプロジェクトが作成済み
・Vercelに環境変数が設定済み
```

## 9. リリース判定基準

### リリース可能

以下を満たす場合、リリース可能とする。

```text
・ローカルでログインできる
・ローカルで1対1チャットできる
・ローカルでRealtime更新できる
・ローカルで画像/ファイル送信できる
・Vercel Previewでbuildが成功している
・Vercel Productionでbuildが成功している
・本番URLでログインできる
・本番URLで1対1チャットできる
・本番URLでRealtime更新できる
・本番URLで画像/ファイル送信できる
・他人のルームにアクセスできない
```

### リリース不可

以下がある場合はリリースしない。

```text
・ログインできない
・usersが作成されない
・チャットルームを作成できない
・メッセージを送信できない
・他人のルームを閲覧できる
・ファイル制限が効いていない
・Vercel buildが失敗する
・Supabase環境変数が不足している
・シークレットがGitに含まれている
```

## 10. リリース責任範囲

学習用MVPのため、リリース責任範囲は以下とする。

| 項目 | 方針 |
|---|---|
| 本番監視 | 最低限。Vercel / Supabase Dashboardで確認 |
| 障害対応 | 手動対応 |
| バックアップ | MVPでは手動確認。将来強化 |
| 切り戻し | Vercelの過去デプロイへ戻す |
| ユーザー告知 | 学習用のため必須ではない |
| 利用規約 | MVPでは未対応 |
| プライバシーポリシー | MVPでは未対応 |

## 11. リリース後に確認するもの

- トップ画面が表示される
- Googleログインできる
- usersが作成される
- ユーザー一覧が表示される
- チャットルームが作成できる
- メッセージ送信できる
- Realtimeで相手画面に反映される
- 画像送信できる
- ファイル送信できる
- 未ログインアクセスが制限される
- 他人のルームにアクセスできない
- Vercelログに重大エラーが出ていない
- Supabaseログに重大エラーが出ていない
