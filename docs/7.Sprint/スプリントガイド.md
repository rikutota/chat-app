# Sprint別実装ガイド一覧

## 概要

チャットWebアプリのSprint別実装ガイド一覧です。  
各Sprintごとに「目的、作るもの、作業手順、完了条件、コミット例」を独立資料として管理します。

---

## Sprint一覧

| Sprint | 資料 | 内容 |
|---|---|---|
| Sprint 0 | `sprint0_setup_guide.md` | プロジェクト準備・環境構築 |
| Sprint 1 | `sprint1_auth_guide.md` | 認証・ユーザー基盤 |
| Sprint 2 | `sprint2_direct_chat_room_guide.md` | ユーザー一覧・1対1チャットルーム |
| Sprint 3 | `sprint3_text_message_guide.md` | テキストメッセージ機能 |
| Sprint 4 | `sprint4_realtime_file_upload_guide.md` | Realtime・画像/ファイル送信 |
| Sprint 5 | `sprint5_release_guide.md` | 仕上げ・テスト・デプロイ |

---

## 進め方

```text
1. 対象Sprintのガイドを読む
2. 作業ブランチを作る
3. タスクを上から順に実装する
4. ローカルで動作確認する
5. コミットする
6. Pull Requestを作る
7. developへマージする
8. 次のSprintへ進む
```

---

## コミットメッセージルール

```text
type: 日本語の説明
```

例:

```bash
git commit -m "feat: ログイン画面を追加"
git commit -m "fix: 空メッセージを送信できないように修正"
git commit -m "docs: READMEに環境変数の説明を追加"
```

---

## コードコメント方針

コードを書くときは、可読性を高めるためにコメントを記述します。

特に以下をコメントします。

```text
・なぜこの処理が必要か
・何を防いでいるか
・セキュリティ上の意図
・将来的な改善ポイント
・MVPで簡略化している理由
```
