# チャットWebアプリ Sprint別開発タスク

## 1. 概要

本資料は、チャットWebアプリMVPを実装するためのSprint別タスクをまとめたものである。

各Sprintでは、目的、作業内容、成果物、完了条件を定義する。

---

# Sprint 0: プロジェクト準備・環境構築

## 目的

開発を始められる状態を作る。

## 主な作業

- GitHubリポジトリ作成
- Next.jsプロジェクト作成
- TypeScript設定
- Tailwind CSS導入
- ESLint / Prettier設定
- ディレクトリ作成
- Supabaseプロジェクト作成
- 環境変数設定
- README作成
- `.env.example` 作成
- docsディレクトリ作成

## タスク一覧

| ID | タスク | 内容 |
|---|---|---|
| S0-01 | リポジトリ作成 | GitHubにリポジトリを作成 |
| S0-02 | Next.js導入 | App Router + TypeScriptで作成 |
| S0-03 | Tailwind導入 | Tailwind CSSを設定 |
| S0-04 | Lint/Formatter設定 | ESLint, Prettierを設定 |
| S0-05 | ディレクトリ作成 | app, components, lib, docsを整理 |
| S0-06 | Supabase作成 | Supabaseプロジェクト作成 |
| S0-07 | 環境変数設定 | `.env.local`, `.env.example` を作成 |
| S0-08 | Supabase Client作成 | browser/server clientの土台 |
| S0-09 | README作成 | 起動手順を書く |
| S0-10 | 初回起動確認 | `pnpm dev` で画面表示確認 |

## 成果物

- Next.jsアプリ
- Supabaseプロジェクト
- `.env.example`
- `README.md`
- 基本ディレクトリ

## 完了条件

- ローカルでNext.jsが起動する
- Tailwind CSSが反映される
- Supabase URLとAnon Keyを環境変数で読み込める
- GitHubに初期コミットがある

- usersテーブル作成

- `getCurrentAppUser` 実装

## タスク一覧

| ID | タスク | 内容 |
|---|---|---|
| S1-01 | Google OAuth設定 | Supabase AuthにGoogleログインを設定 |
| S1-02 | usersテーブル作成 | SQLでusersテーブル作成 |
| S1-03 | `/api/me` 実装 | ログイン中ユーザー取得・作成 |
| S1-04 | getCurrentAppUser実装 | API共通のユーザー取得関数 |
| S1-05 | ログイン画面作成 | `/login` 作成 |
| S1-06 | ログイン処理実装 | Supabase Authでログイン |
| S1-07 | ログアウト処理実装 | Headerやプロフィールからログアウト |
| S1-08 | 認証ガード実装 | 未ログイン時に/loginへ遷移 |
| S1-09 | プロフィール画面作成 | `/profile` 作成 |

## 成果物

- ログイン画面
- プロフィール画面
- usersテーブル
- `/api/me`
- 認証ガード

## 完了条件

- Googleログインできる
- 初回ログイン時にusersレコードが作成される

- `/api/chat-rooms/direct` 実装
- `/api/chat-rooms` 実装
- チャットルーム一覧画面作成
- ルーム重複確認処理実装

## タスク一覧

| ID | タスク | 内容 |
|---|---|---|
| S2-01 | ルーム系テーブル作成 | direct_chat_rooms, members作成 |
| S2-02 | `/api/users` 実装 | 自分以外のユーザー一覧取得 |
| S2-03 | ユーザー一覧画面作成 | `/users` 作成 |
| S2-04 | findOrCreateDirectRoom実装 | 既存ルーム確認・作成 |
| S2-05 | `/api/chat-rooms/direct` 実装 | 相手指定でルーム作成/取得 |
| S2-06 | `/api/chat-rooms` 実装 | 自分のルーム一覧取得 |
| S2-07 | チャット一覧画面作成 | `/chats` 作成 |

## 成果物

- ユーザー一覧画面
- チャットルーム一覧画面
- 1対1チャットルーム作成API
- ルーム一覧取得API

## 完了条件

- ユーザー一覧に自分以外のユーザーが表示される
- ユーザーを選ぶと1対1チャットルームが作成される

- 権限チェック実装

## タスク一覧

| ID | タスク | 内容 |
|---|---|---|

| S3-04 | メッセージ一覧API実装 | `GET /api/chat-rooms/:roomId/messages` |
| S3-05 | メッセージ送信API実装 | `POST /api/chat-rooms/:roomId/messages` |
| S3-06 | チャット画面作成 | `/chats/[roomId]` 作成 |
| S3-07 | MessageList作成 | メッセージ一覧表示 |
| S3-08 | MessageInput作成 | 入力欄、送信ボタン |

## 成果物

- チャット画面
- メッセージ一覧表示
- テキストメッセージ送信
- ルーム参加者チェック

## 完了条件

- チャット画面を表示できる
- メッセージ履歴を表示できる
- テキストメッセージを送信できる

- 自分が参加していないroomにはアクセスできない
